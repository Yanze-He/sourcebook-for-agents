# Sourcebook Logo Kit

## Folder guide

- `flat/`: the canonical, scalable flat mark for the website, README, browser tab, and extension.
- `desktop/`: the current 3D macOS application icon artwork and its `.icns` bundle.
- `installer/`: the current 3D DMG icon artwork, plus the previous flat installer variant for reference.

## Recommended files

- Website and documentation: `flat/sourcebook-flat.svg`
- Browser tab: `flat/sourcebook-flat-mark.svg`
- Browser extension: `flat/png/sourcebook-flat-16.png` through `sourcebook-flat-128.png`
- macOS application: `desktop/sourcebook-desktop-3d.icns`
- DMG volume and downloaded DMG file: `installer/sourcebook-installer-3d-1254.png`
