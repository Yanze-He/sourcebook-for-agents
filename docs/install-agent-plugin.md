# Install or update the Sourcebook Agent Plugin

The Sourcebook Agent Plugin now has its own [public distribution repository](https://github.com/Yanze-He/sourcebook-plugin). Follow that repository's [current installation guide](https://github.com/Yanze-He/sourcebook-plugin/blob/main/INSTALL.md) for Codex or WorkBuddy.

Sourcebook Desktop must be installed and running before an Agent can use a Book. The landing page is maintained privately; its source is not part of either public repository.
