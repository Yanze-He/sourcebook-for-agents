# Use Cases

Sourcebook is for people who already work with AI agents and want to carry the right material into the next task without repeating the entire backstory.

## Research that continues across agents

**For:** independent researchers, product managers, and analysts.

Pick the key paragraph from an article, the product page that defines a constraint, and the few chat messages where a decision was reached. Keep them in one Book for the project, add a note about the open question, then prepare a Pack for the next research or writing task.

The point is not to archive the whole web. It is to carry a small, inspectable set of references forward with their original links.

## Multi-model work without lock-in

**For:** people who move between ChatGPT, Gemini, DeepSeek, Grok, and other AI tools.

Pick the messages and web material that matter while you work. When the next task belongs in another agent, prepare a Pack with the selected local files, links, and instructions. Sourcebook does not send anything automatically and does not require you to stay in one model.

## Project context for an agent workflow

**For:** developers and builders creating repeatable agent-assisted workflows.

Create a Book for a project. Collect source material in the browser, import local files, or create Sources through the local API. Review, annotate, and select only the inputs that belong to the next task.

Books keep unrelated projects separate: each has its own local database and assets. Sources can be copied or moved deliberately when a reference belongs in more than one project.

## What Sourcebook is not for

- A full-page web archive, video downloader, OCR tool, or automatic chat-history sync.
- A shared cloud workspace, team wiki, or Notion replacement.
- A new AI chat application that chooses or sends context for you.

Sourcebook works best when you want a deliberate, local handoff between the work you have already done and the next agent task.
